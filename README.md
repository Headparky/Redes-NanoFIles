# Redes - NanoFIles
Sistema P2P para compartir ficheros que utiliza un servidor de directorio y múltiples peers que actúan como cliente y/o servidor.

Se han diseñado protocolos como UDP para la comunicación entre peers y directorio con mensajes en formato "campo:valor" y el protocolo TCP para la comunicación entre peers con mensajes binarios para listar y transferir ficheros
